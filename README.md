# Sensor de luz com placa aberta

### Side note

Este trecho foi anotado durante os estudos e nao substitui a documentacao oficial.


Leitura de um divisor com sensor foto-resistivo, imprimindo o valor na porta serial.

Quando a luz ambiente cai abaixo do limite configurado, o sketch acende um LED de aviso — a mesma lógica usada depois nos olhos do exterminador.
